Game trainer for Windows

Start it. Start your game. Click what you want.

A small, fast trainer that finds your game on its own and keeps its scripts up to date.

Download Source
Windows 10/11 · one exe, no installer · single-player games only

Supported games

Each game is a small script. New games and fixes arrive on their own — the trainer syncs its scripts from GitHub.

How it works

No setup, no config files to find, nothing to install.

1

Download

Put az_trainer.exe in a folder of its own. On first start it downloads the game scripts next to itself.

2

Start your game

The trainer detects which supported game is running and attaches to it automatically.

3

Click what you want

Toggle options in the window or with their shortcuts. Close the trainer and everything is put back.

Features

Small on purpose, careful where it matters.

Finds the game and its version

Attaches on its own, and a script never touches a build it was not made for.

Keyboard shortcuts

Global hotkeys like Alt+F1, with a brief on-screen notice in game.

Updates itself

New trainer versions, new games and fixes arrive without you downloading anything.

Remembers your settings

Each game keeps the options you had on, ready for next time.

Shows what is loaded

The loaded script's update date, checksum and a link to its source, right in the window.

Open scripts

Every game is one readable JavaScript file. Add your own.

Single-player only. Do not use with online or competitive games. Releases · Developing · GitHub
